How you can check
  • Airplane mode. Everything the page needs is inside it, so once it has loaded it works with no connection at all.
  • Your browser's developer tools. The Network tab shows one request, for the page itself, and choosing a file adds none. Cloudflare, which hosts earnrate.dev, adds its visit-counting script to the site's pages; on this one the console shows the browser refused it.
  • The page source. It's one file, with the code that reads your statement written into it, and its security policy is the first meta tag after the character set.

The policy, which your browser enforces whatever the page's code tries:

What each part means

  • default-src 'none': the page may load nothing, from anywhere, unless a rule below allows it.
  • script-src 'sha256-…': it runs only the one script written into the page, the one with that SHA-256 fingerprint. If a single character of it changed, or another script were added, your browser would refuse to run it. It can't load a script from anywhere, even earnrate.dev.
  • style-src 'sha256-…': the same for the page's styles, so they can't be changed or added to either.
  • img-src data:: images only from inside the page, like its icon.
  • connect-src 'none': its code can't make a request of any kind, so it can't upload or report anything.
  • form-action 'none': no form on it can send anything.
  • base-uri 'none' and frame-ancestors 'none': nothing can change where its links lead, and no other site can show it inside its own page.

Links still work: following one opens another page and leaves the file behind.
