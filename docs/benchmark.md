# Benchmark: earnrate vs RightCard

Golden cases from `tests/golden/`, run through RightCard's `best_card` tool and earnrate's `recommend()`, plus a merchant coverage count for both.

## Setup (2026-11-03)

- **RightCard:** `rightcard-mcp@0.1.17` (published 2026-10-28), the latest on npm, installed in a temp directory and driven over stdio with `@modelcontextprotocol/client`. It reads its live public catalog when it starts, so this run reflects that catalog on 2026-11-03.
- **earnrate:** `main` at `4eef2fd`, data `2026.11.02.5`. The coverage count is also given for data `2026.11.03.1`, which adds the merchants this run found missing.
- **Wallet:** the same nine cards in both. RightCard ids: `amex_gold`, `amex_blue_cash_preferred`, `amex_platinum`, `chase_sapphire_preferred`, `chase_freedom_unlimited`, `amazon_prime_visa`, `usbank_cash_plus`, `citi_my_best_buy_visa_card`, `sofi_credit_card`, all marked `verified`. The Freedom Flex cases add `chase_freedom_flex`. The earnrate wallet is `tests/golden/fixtures.ts`: Prime membership, Cash+ Q4 picks of 5% on TV/internet/streaming and movie theaters and 2% on gas/EV, and SoFi redeemed into a SoFi account.
- **Valuation:** RightCard has two fixed modes. `cash` caps points at 1¢, which matches our `flat`. `points` uses a fixed 1.8¢ for MR and UR, close to our `points-heavy` at 1.7¢. RightCard doesn't let you pass your own values.
- **Inputs:** both got the same merchant strings. Both ran on the golden tests' date, 2026-10-24 (RightCard's `on` input), except cases that set their own date. earnrate gets the state a case needs (cap usage, activation, channel, country). RightCard has no input for amount, channel, cap usage, memberships, activation or country, and returns a single winner. earnrate returns a ranked list. RightCard's `chosen_categories` input, new since the last run, covers Custom Cash, Customized Cash and a few others, but not Cash+.

To reproduce RightCard's side, install `rightcard-mcp@0.1.17` outside this repo and call `best_card` with `{ wallet, merchant, valuation: 'cash' | 'points', on }` for each row. earnrate's side is `yarn vitest run tests/golden`.

## Merchant coverage

A list of 323 well-known U.S. merchants, in `docs/benchmark-merchants.txt`: the largest chains in each earnrate category, by name only, from public rankings (Progressive Grocer's and NRF's largest retailers, QSR's 50 and the largest full-service restaurant chains, the largest convenience and fuel brands), plus common online services, airlines, hotels, transit agencies and utilities. Each name was given to earnrate's `resolveMerchant` and RightCard's `lookup_merchant` as typed. A merchant counts if the tool matched it to a business in its directory. We spot-checked RightCard's matches against the names and found no wrong business. We don't publish its categories.

| Directory                           | Merchants matched |
| ----------------------------------- | ----------------- |
| earnrate, data `2026.11.02.5` (168) | 95 of 323 (29%)   |
| earnrate, data `2026.11.03.1` (385) | 311 of 323 (96%)  |
| RightCard 0.1.17                    | 315 of 323 (98%)  |

A match doesn't mean a bonus category: RightCard files many stores under its "general" category, and earnrate files pet, beauty and craft stores under "everything else", because no issuer gives them a bonus in store. earnrate's count includes "Amazon Music", which still matches Amazon as an online retailer; that's a known wrong match, not a streaming service.

- **RightCard misses 8:** Dillons, QFC, Comcast, and all five EV charging networks (Tesla Supercharger, Electrify America, ChargePoint, EVgo, Blink).
- **earnrate misses 12**, on purpose for now: TJ Maxx, Victoria's Secret, GameStop and Harbor Freight (department store or clothing, and specialty-store codes, vary), Shipt and Thrive Market (how they code isn't clear), Temu and Shein (Amex's online retail bonus needs a U.S. merchant), StubHub, SeatGeek and Vivid Seats (resale tickets may not code as entertainment), and bare "Budget" ("Budget Car Rental" matches; the bare word would also catch "Budget Inn"). A wrong category is worse than a missing merchant, since unknown merchants fall back to base rates and say so.

Nothing on the list was missed by both.

## Where RightCard is still ahead

- **Breadth past the big chains.** On the untrimmed 489-name draft of the list (more regional grocers, restaurants and apparel chains), RightCard matched 464 and earnrate 334. Its directory has curated aliases and family collapsing, and 3,100+ cases checked against its iOS app. earnrate's answer for the long tail is still its optional Claude merchant lookup.
- **Portal notes.** It mentions the Amex Travel portal on airline purchases. earnrate mentions issuer travel sites only when one would earn more.

Things RightCard did well that earnrate matches: the next-best card after a cap, points pooling, and explained tie-breaks. It now also gets Costco's Visa-only registers and Sapphire Preferred's gas rate right.

## What changed since 2026-10-24

- **RightCard (0.1.14 → 0.1.17):** Costco's Visa-only registers, Sapphire Preferred's 3x gas, a date input for rotating windows, and choose-your-category input for some cards.
- **earnrate:** golden cases #15–#22 (Cash+'s shared cap, recorded spending, networks, points pooling, missing rotating quarters, period rollover, Freedom Flex activation, purchases abroad); Freedom Flex's 2027-Q1 categories; a fine-print pass over every card; and 217 more merchants (`data/CHANGELOG.md`, `2026.11.03.1`).
